# 球を風で30cm動かす実験

## 目的

CoDrone EDU の本体先端から前方 `10cm` に置いた、直径約7cmの穴あきプラスチック製pickleballを、機体の風で前方向へ `30cm` 動かす。

CoDrone EDU は球の実移動量を直接測れないため、コードは以下を担当する。

- 前方距離、バッテリー、高度などを毎回ログ化する。
- 同じ風条件を再現して出す。
- 離陸前に前方距離センサで球が見えていることを確認する。
- 離陸後の前方距離センサ値はログ化するが、床上のpickleballを拾えないため安全判定には使わない。
- 高度が `25cm` 未満になったら接触防止のため中止する。
- 実験後に人間が測った球の移動量を同じJSONLログとCSVへ追記する。

## 実行ファイル

- `ball_wind_experiment.py`
- ログ保存先: `ball_wind_logs/*.jsonl`
- 測定一覧CSV: `ball_wind_logs/measurements.csv`
- 目視用の最新ログ: `ball_wind_logs/latest_run.log`

## 基本実行

```powershell
python ball_wind_experiment.py run
```

実験後、球が実際に動いた距離を追記する。

```powershell
python ball_wind_experiment.py measure ball_wind_logs\ball_wind_YYYYMMDD_HHMMSS.jsonl --actual-cm 24.5 --notes "床:グレーのフローリング 球:pickleball"
```

## 変更する変数

まず触る場所は `ball_wind_experiment.py` 先頭の `ExperimentConfig` に限定する。

最優先で調整する値:

- `blow_duration_sec`
  - 風を当てる時間。
  - 最初に触る。
  - 目安: `0.35` から `1.50`
- `blow_pitch_power`
  - 前後方向の風の強さに効く主変数。
  - 時間だけでは足りない場合に触る。
  - 目安: `8` から `30`
- `blow_repeats`
  - 風パルス回数。
  - 1回の強風で結果が荒れる場合に、弱い風を複数回へ分ける。
- `target_front_clearance_cm`
  - 球との初期距離。
  - 離陸前に、ドローン本体先端から球の手前端までの距離。
  - 基本は `10.0` のまま。

安全上、通常は触らない値:

- `preflight_front_range_min_cm`
  - 離陸前に球が近すぎないかを見る下限。
- `preflight_front_range_max_cm`
  - 離陸前に球が遠すぎないかを見る上限。
- `minimum_safe_height_cm`
  - 接触防止のための最低高度。
  - 基本は `25.0` のまま。
- `minimum_battery_percent`
- `keep_height_guard_enabled`

## 実験サイクル

### 1. セットアップ固定

毎回そろえる条件:

- 床材
- 球の種類、直径、重さ
- 球の初期位置
- 床材: グレーのフローリング
- ドローンの向き
- バッテリー残量
- 周囲の風
- 離陸地点

メジャーやテープで、球の初期位置と30cm到達位置を床に印を付ける。

ボール位置確認:

- 正確な基準は「離陸前にドローン本体先端から球の手前端まで10cm」。
- 前方距離センサ値はセンサ面基準なので、本体先端10cmと完全一致しない。
- コードは離陸前だけ、前方に球が見えているかを確認する。
- 離陸後は床上のpickleballが前方センサ視野から外れるため、`front_range_cm` は安全判定に使わない。

### 2. 低出力で方向確認

最初は `blow_pitch_power=8` から `12`、`blow_duration_sec=0.4` から `0.7` で始める。

判断:

- 球が目標方向へ動く: 次へ進む。
- 球が動かない: `blow_duration_sec` を増やす。
- 球が横へ逃げる: 球の中心線、床の傾き、機体の向きを直す。
- ドローンが球に近づきすぎる: `blow_pitch_power` を下げるか、実験中止。

### 3. 3回同条件で測る

同じ設定で最低3回実行する。

記録する値:

- `actual_ball_move_cm`
- 球がまっすぐ進んだか
- 横ズレ
- 接触の有無
- ドローンのふらつき

1回だけの結果では判断しない。

### 4. 解析

見る順番:

1. `manual_measurement.actual_ball_move_cm`
2. `target_ball_move_cm - actual_ball_move_cm`
3. `manual_measurement.measurement_status`
4. `sample` の `height_cm`
5. バッテリー
6. `front_range_cm` は参考値としてのみ見る

判断:

- 27cmから33cm: 設定を変えず、再現性確認。
- 30cm未満: まず `blow_duration_sec` を `+0.15` 秒。
- 30cm超過: まず `blow_duration_sec` を `-0.10` 秒。
- 時間が `1.5` 秒以上でも不足: `blow_pitch_power` を `+2`。
- 時間が `0.35` 秒以下でも超過: `blow_pitch_power` を `-2`。

### 5. 修正

一度に変更する主変数は1つだけにする。

推奨順:

1. `blow_duration_sec`
2. `blow_pitch_power`
3. `blow_repeats`
4. `target_front_clearance_cm`

理由:

- 時間は一番再現性が高く、機体姿勢への影響が少ない。
- pitchは強く効くが、ドローン自身の移動や接触リスクも増える。
- repeatsは非線形な転がりや摩擦のばらつきをならすために使う。
- 初期距離は風の当たり方を大きく変えるため、最後に触る。

## 最適化方針

最終的には、平均値だけでなくばらつきを見る。

採用条件:

- 5回中4回以上が `27cm` から `33cm`
- 接触なし
- 球の横ズレが許容範囲
- ログ上、高度が `25cm` 未満に入っていない
- バッテリー差で結果が大きく変わらない

ばらつきが大きい場合:

- 強い1発より、弱い複数パルスへ変更する。
- `blow_pitch_power` を下げ、`blow_repeats` を増やす。
- 球と床の摩擦条件を固定する。
