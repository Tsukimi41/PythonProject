# 2026-07-07 多軸最速 PID 制御

## 変更目的

最終目標を x 軸中心の高速移動から、x/y/z の相対移動指令に対して同じ制御思想を適用する構成へ改定した。

重点は次の通り。

- x/y/z の各軸で、最大加速、制動距離予測、急制動、PID 精密停止へ遷移する。
- 風、干渉、物理的妨害で目標から離れた場合も、センサが復帰すれば再収束を続ける。
- 逆走や最良到達点からの大きな離脱は軸ごとに検知し、安全停止する。
- pitch/roll の水平合成入力が過大にならないよう、ベクトル量を制限する。

## 実装内容

- `AxisRapidState` を追加し、軸ごとに高速フェーズを管理するようにした。
- `move_relative_mm()` で x/y/z それぞれに高速移動フェーズを適用した。
- `control_phase_y`, `control_phase_z`, `predicted_remaining_y_mm`, `predicted_remaining_z_mm`, `stopping_distance_y_mm`, `stopping_distance_z_mm` をログへ追加した。
- CLI に `--max-roll`, `--brake-roll`, `--max-throttle`, `--brake-throttle` を追加した。
- 自動 PID 更新は x/y/z 全軸の最終誤差が異常に大きくない場合だけ行うようにした。
- 実機なしテストで x/y/z の最大加速と急制動フェーズを確認した。

## 理論上の限界

CoDrone EDU 単体の光学フロー、ToF、IMU だけでは、強風や接触外乱下で絶対位置を数学的に厳密保証することはできない。センサが位置を更新できない、床面特徴が不足する、機体が押さえ込まれる、または通信遅延が続く場合、制御器は出力を上げ続けず安全停止する。

厳密な最終位置保証をさらに高めるには、外部モーションキャプチャ、UWB、AprilTag などの外部測位を追加し、この制御器の `SensorSnapshot` 入力へ融合する必要がある。

- Y は過大加速ではなく、終盤の横方向の押し戻し/ドリフトに対して補正力が不足している。
- PIDのP/D項だけで指令を出すと、速度項や微分項により「まだ遠いのに弱い出力」または「早すぎる逆出力」が起きる。
- 短距離の最終調整はPID単独ではなく、残距離から許容速度を計算する時間最適寄りの速度サーボにする方が筋がよい。

追加修正:

- 短距離 `settle` フェーズでは、PID出力を主役にせず、残距離から目標速度を計算する速度サーボ制御へ切り替えた。
  - 遠い場合: 目標方向へ十分な最小出力を出す。
  - 制動距離内で速く接近している場合: PIDが加速を要求してもブレーキする。
  - 外乱で押し戻された場合: 再び目標方向へ戻す。
- X短距離で古いプロファイルから `pitch_cmd=55` が出ないよう、pitchの出力上限を `42-50` に正規化した。
- 高度が急落した場合は水平移動を捨て、`pitch=0, roll=0, yaw=0, throttle=80` で高度回復を最優先するガードを追加した。
- 高度回復中にセンサ更新が止まった場合、または高度が危険域/ヨーが大きく崩れた場合は `sensor_timeout` / `altitude_fault` / `attitude_fault` として安全停止する。
- 通常の位置センサ停止閾値を `1.20s -> 0.65s` に短縮した。
- 速度サーボの「遠いときは戻す」「近くて速いときはブレーキ」をユニットテスト化した。

次回推奨:

```powershell
python main.py --x-mm 300 --no-auto-tune
python main.py --y-mm 300 --no-auto-tune
```

確認:

- x=300 で `pitch_cmd` 初期値が 55 まで出ず、水平移動中に高度が急落した場合は `throttle_cmd=80` へ切り替わること。
- y=300 で `final_error_y_mm` が 70mm 帯から縮むこと。
- 位置/モーション更新停止時に35秒まで粘らず `sensor_timeout` で止まること。

- y 目標自体は最終的にほぼ合っているが、yaw が -24 度までずれ、X方向に大きく逃げた。

- yaw誤差が 8 度を超えたら水平出力を段階的に下げ、22 度を超えたら pitch/roll を最大 8 に制限するようにした。
- 座標変換の逆変換性と yaw=90 度での変換をユニットテスト化した。
