# experiment_logs

このディレクトリは、CoDrone EDU の PID 制御改善に関する実験記録をMarkdownで残すための場所である。

目的は次の 3 点である。

1. 何を変更したかを後から正確に追跡できるようにする。
2. どのログをどう読んで評価したかを再現できるようにする。
3. 次回の飛行実験で何を見るべきかを明確にする。

収録ファイル:

- `2026-06-30_変更詳細.md`
  - 今回実施したコード変更の詳細、意図、期待効果、残課題をまとめた記録。
- `2026-07-07_多軸最速PID制御.md`
  - x/y/z の多軸最速 PID 制御化、ログ追加、次回実機確認手順をまとめた記録。
- `2026-07-14_球風移動実験.md`
  - 前方10cmの球を風で30cm動かす実験の手順、ログ運用、調整変数をまとめた記録。
- `実験履歴サマリー.md`
  - 既存 `flight_logs` の要約と、そこから読める傾向の整理。
- `解析方法.md`
  - ログの見方、評価基準、次の実験時の解析手順を詳細に記した手順書。

運用ルール:

1. コード変更を行ったら、同日に新しい Markdown を追加するか、既存の日付ファイルへ追記する。
2. 実機飛行を行ったら、対応する `pid_flight_*.jsonl` の要約を `実験履歴サマリー.md` に追記する。
3. 解析方法を変えた場合は `解析方法.md` を先に更新してから次回実験を行う。
4. 実験の評価は必ず `x`, `y`, `z`, `yaw`, 所要時間, オーバーシュート, センサ鮮度の 7 観点で書く。
